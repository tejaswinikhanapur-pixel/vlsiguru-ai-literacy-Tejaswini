## Week 01 Learning Summary

During Week 01, I developed a basic understanding of the current AI landscape. I learned that AI is a broad field, while ML and DL are approaches used to build AI systems. Generative AI can create new content such as text, code, images, and other forms of data.

I also learned that AI-generated answers should not automatically be treated as correct. AI systems can produce incorrect information, so important technical information needs to be checked against reliable sources.

The main lesson I learned this week is that AI should be used as an assistant for learning and problem-solving, while human verification and judgment remain important.
